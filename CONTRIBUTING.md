# Contributing to zsh-patina

Thank you so much for your interest in improving zsh-patina! This document is intended for everyone who is considering opening an issue or a pull request.

## What to Contribute

We accept any kind of contribution: bug fixes, new features, documentation improvements, new themes, etc. Any help is appreciated!

## Rules

There are only two rules so far:

* Please follow our [AI Usage Policy](#ai-usage-policy) below
* By submitting a contribution, you agree that your code is licensed under the [MIT license](LICENSE).

That's all we ask for the time being. As the number of issues and pull requests increases, more rules may be added. So, please make sure to check this document for updates whenever you make a new contribution.

## AI Usage Policy

First things first: **AI assistance is allowed.**

**However, it's not always useful.** This section lists a few things to consider when submitting an issue or a pull request using AI.

* **Any use of AI must be disclosed.** Please include which tool (Claude Code, Cursor, etc.) and model(s) (Fable, Opus, GPT-Codex, etc.) you used in the issue or pull request description.
* **Describe how AI has assisted you.** Please include a short description of how you've used AI in your contribution and what exactly was generated.
* **You must understand the code you submitted.** As a human, you are responsible for the code your AI has generated and for what you contribute to this project. Please refrain from submitting code that you haven't reviewed carefully or that you don't understand.
* **Try to avoid slop.** Remember that zsh-patina is maintained by humans who need to read your issue descriptions and your pull requests. Please try to avoid unnecessary content in issue descriptions and check if what your AI has written is actually valid and true. 

**Note:** The goal of this policy is not to restrict AI usage or to forbid it completely. As a matter of fact, we are AI users too and some parts of zsh-patina have been developed with AI assistance (although the majority of the code is handwritten, especially the critical paths).
